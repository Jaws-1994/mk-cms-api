# Documentation du projet

Cette documentation décrit l’installation et l’état actuel de MK CMS API.

## Guides

- [Installation et configuration](installation.md) : prérequis, variables
  d’environnement et commandes utiles.
- [Référence de l’API](api.md) : routes disponibles, requêtes et réponses.
- [Base de données](base-de-donnees.md) : tables et colonnes utilisées par
  l’application.

## État du projet

Le dépôt contient une application Nuxt 4, une page d’accueil minimale et des
routes Nitro pour tester MySQL et gérer l’inscription, la connexion et la
consultation du profil. Il ne contient pas de migration ou de script de création
de la base de données.
